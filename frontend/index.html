About The Event

Where Campus Developers Meet The Google Cloud

CloudPort is engineered by the Google Developer Groups On Campus BPPIMT Cloud Team to bridge theoretical concepts with enterprise-grade cloud development.

Serverless Computing

Build event-driven microservices with Google Cloud Functions. Learn zero-infrastructure serverless patterns, automatic horizontal scaling, and HTTP triggers.

Cloud Firestore Native

Store structured, real-time NoSQL documents with Google Cloud Firestore in Native mode. Learn collections, schema design, and server timestamps.

IAM & Cloud Security

Implement strict Least-Privilege service accounts, Application Default Credentials (ADC), environment segregation, and CORS security.

Static Web Hosting on GCS

Deploy high-availability frontends on Google Cloud Storage buckets or Google Cloud Run with fine-grained caching, HTTPS, and low latency.

Event Curriculum & Schedule

What You Will Experience at CloudPort

A comprehensive curriculum covering architecture design, live coding, and production deployment on Google Cloud Platform.

1
Session 01 • Foundation Day 1

Google Cloud Foundations & Firestore Native Modeling

Setting up GCP projects, Cloud SDK (gcloud CLI), billing safeguards, and creating Firestore in Native mode with granular IAM roles.

  • GCP Resource Hierarchy & Service Accounts
  • Cloud Firestore collections and document modeling
  • Configuring Application Default Credentials (ADC)
2
Session 02 • Core Engineering Day 2

Serverless API Development with Google Cloud Functions

Building, packaging, and deploying HTTP-triggered Cloud Functions (Gen 2) with input validation, error handling, and Firestore integration.

  • Writing HTTP endpoints with Functions Framework (Node.js & Python)
  • Handling CORS preflight (OPTIONS) and method constraints
  • Writing server-side timestamps & validation checks
3
Session 03 • Deployment & DevOps Day 3

Frontend Hosting, Cloud Run & Infrastructure as Code

Deploying responsive static web assets to Google Cloud Storage, connecting frontend fetch APIs, and automating with Terraform.

  • Public bucket web hosting & Cloud Run alternative
  • Connecting frontend fetch API to the live Cloud Function
  • Automating cloud provisioning with Terraform IaC
